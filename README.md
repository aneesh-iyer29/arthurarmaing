# arthurarmaing

The official personal website of Arthur R. Mank, a Georgia Tech student who
paraglides into the world, pulls out his Sheikah Slate, and finds that the
entire map is Aneesh Iyer's face.

Plain static site: `index.html`, `style.css`, `script.js`, and `img/`. No build step.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Works as-is on GitHub Pages, Vercel, Netlify, or Cloudflare Pages. For GitHub
Pages with the custom domain, add a `CNAME` file containing the domain and
point the domain's DNS at GitHub Pages.
